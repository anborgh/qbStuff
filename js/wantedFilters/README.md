# Фильтр заявок в теме поиска

Список ролей по фандомам, фильтр по фандому / персонажу / тегу и компактная форма для вставки блоков заявки в ответ.

## Подключение

В html-низ (номера тем заменить на свои):

```html
<script src="https://forumstatic.ru/files/0017/95/29/51757.js"></script>
<script>
  hvWantedFilters.init(999, 998, 997);
</script>
```

Скрипт запускается только в указанных темах.

### Агрегация заявок из нескольких тем

Если в одной теме нужно собрать заявки из нескольких тем:

```html
<script>
  hvWantedFilters.init([999, 998], 997);
</script>
```

- в теме `999` — полный режим: список, фильтры, форма;
- в теме `998` — только форма ответа (без списка/фильтров);
- в теме `997` — отдельный полный режим по своим заявкам.

## Разметка в стартовом посте

Там, где нужен список ролей:

```
[block=charlist][/block]
```

Облако тегов (опционально):

```
[block=tags][/block]
```

Не ставить эти блоки в спойлер / медиа / html-блок — иначе они не заработают.

## Разметка в заявке

| Блок | Назначение |
|------|------------|
| `[block=fd]...[/block]` / `.fd` | фандом |
| `[block=nm]...[/block]` / `.nm` | имя персонажа |
| `[block=tg]...[/block]` / `.tg` | теги (можно несколько или через запятую в одном) |

Несколько фандомов в одной заявке: перед каждой группой имён свой `.fd`; имена относятся к ближайшему предыдущему фандому.

Пример:

```html
[block=fd]MCU[/block] [block=nm]Loki[/block] [block=nm]Thor[/block]
[block=fd]Harry Potter[/block] [block=nm]Hermione Granger[/block]
[block=tg]в пару, приключения[/block]
```

## Форма ответа

Если есть форма ответа, после кнопок форматирования появляется helper:

- фандом / имя / `+` (до 3 фандомов) / тэги / `↓`;
- `↓` или Enter вставляет блоки в позицию курсора;
- autocomplete по уже собранным фандомам и тегам;
- поле «тэги» только если в стартовом посте есть `[block=tags][/block]`;
- без возможности ответа форма не показывается.

## Фильтры

Клик по фандому, персонажу или тегу фильтрует тему (URL: `?fandom=`, `?post=`, `?tag=`).  
Фандом и тег комбинируются (AND). Сброс — «x Сбросить фильтр».
Можно делиться ссылкой с применёнными фильтрами, другой пользователь увидит уже отфитльрованную тему.

## Стили

Основные классы:

- `.post .charlist`, `.charlist_fd`, `.charlist_item`, `.charlist_title`
- `.post .tags`, `.tags_item`
- `.hvWantedHelper`, `.hvWantedSuggest` — форма и autocomplete

## Callback

После рендера отфильтрованных постов можно повесить свои скрипты:

```js
hvWantedFilters.callback(function ($list) {
  // $list — контейнер .hvFilteredList
});
```
